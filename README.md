#Página para controle de evento.

Foi solicitado pelo Distrito de Rotary Clubs 4470 uma forma simples de se controlar a presença na 48ª Conferência do Distrito.

O sistema foi desenvolvido em Flask sendo um painel administrativo para consultar as presenças e ausências no evento, em paralelo foi criado e impresso Crachás com um QrCode que apontava para este portal e confirmava a presença da pessoa ao ser lido.

Diante da necessidade de um sistema que tivesse um custo extramemente baixo, utilizei de uma planilha do Google Sheets para servir como Banco de Dados para este sistema.
